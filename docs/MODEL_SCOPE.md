# Model Scope

## Release Position

`Ogaal ASR` is a Somali automatic speech recognition model released by Ogaal Labs.

## Intended Use

- Somali speech transcription
- local CLI transcription
- local browser demo transcription
- developer integration for Somali voice products

## Training Intent

This model was intentionally trained for Somali speech recognition.

English was not part of the training objective for this release.

## Public Description

- a Somali ASR model
- based on `openai/whisper-large-v3`
- trained on roughly 72 hours of Somali speech
- released by Ogaal Labs for practical Somali transcription workflows

## Data Story

The release includes a private Ogaal Labs collection effort built around roughly 5,000 curated prompts recorded by 19 speakers across varied genders, accents, and speaking styles.
